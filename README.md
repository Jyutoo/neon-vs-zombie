# 奶龙大战僵尸

一款以“奶家人”为主题的植物大战僵尸式网页塔防游戏。收集奶黄、放置奶蛋与十二生肖，守住五行奶家小院。

当前版本为 **电脑浏览器单关完整试玩版（第三轮修复）**，使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 启动游戏

- Windows：双击 `启动游戏.bat`。
- 也可以直接用浏览器打开 `index.html`。
- 如需本地服务，在项目目录运行 `python -m http.server 4173`，再访问 `http://127.0.0.1:4173`。

## 基本操作

1. 点击发光的奶黄收集资源：自然掉落为 25 点，奶蛋生产为 20 点。
2. 点击左侧角色卡牌，再点击空草地放置。
3. 使用小铲子可以移除已放置的角色。
4. 点击每行最左侧的奶娃，会在奶娃原格内播放无白底、不缩放的捧腹大笑视频与原声，并清空本行僵尸；僵尸突破时也会自动触发，每行限用一次。
5. 空格暂停或继续，数字 `1` / `2` 切换速度，`Esc` 或鼠标右键取消选择。

## 角色能力

所有角色的购买冷却在首版基础上统一增加 1 秒（奶蛋 5 秒、奶鼠 5 秒、奶蛇 7 秒、奶龙 11 秒、奶兔 9 秒、奶虎 9 秒、奶牛 11 秒、奶猴 8 秒、奶羊 9 秒、奶马 10 秒、奶鸡 10 秒、奶猪 9 秒、奶狗 8 秒）。

| 角色 | 定位与能力 |
| --- | --- |
| 奶蛋 | 每 12 秒生成 20 奶黄，成本 60 |
| 奶鼠 | 远程投掷石头，稳定单体输出 |
| 奶蛇 | 毒液命中后造成持续伤害，攻击时发出短促喷吐声 |
| 奶龙 | 范围火焰，对目标及附近僵尸造成伤害 |
| 奶兔 | 治疗自身及周围八格的伙伴 |
| 奶虎 | 高伤害、快速近战攻击，攻击时带有挥击声 |
| 奶牛 | 900 点耐久，负责阻挡与近身顶撞，攻击时带有低哞声 |
| 奶猴 | 每次攻击本行两个目标，发射果核时带有两声轻响 |
| 奶羊 | 造成伤害并击退僵尸；击退后目标获得抗性，不会立刻被连续弹开 |
| 奶马 | 中距离冲锋，造成伤害并撞退目标；同样受击退抗性保护 |
| 奶鸡 | 提高本行其他奶家人 25% 攻击速度 |
| 奶猪 | 每 13 秒额外产出 25 奶黄 |
| 奶狗 | 吠叫减速本行僵尸，近身时撕咬 |
| 奶娃 | 每行一次，在奶娃原位播放大笑视频与原声并清空本行僵尸 |

> 击退机制：奶羊、奶马保留原有伤害与击退距离。僵尸第一次被弹开后获得 4 秒击退免疫，并持续免疫到它击杀当前阻挡角色为止；处于啃食状态的僵尸不会被弹开。这样僵尸能重新靠近并攻击奶羊或奶马，避免被永久锁在攻击距离外。

## 敌人能力

所有僵尸的移动速度在首版基础上降低约 10%：普通/路障 11、铁桶 9、快速 16、大块头 5.5、远程 8、跳跃 20、僵尸王 3.8。

| 敌人 | 定位与能力 |
| --- | --- |
| 普通、路障、铁桶、快速僵尸 | 血量已提高约 25%，保留不同护甲与速度定位 |
| 大块头僵尸 | 1100 点耐久，移动缓慢；重击对目标造成 60 点伤害，并波及相邻角色 |
| 远程僵尸 | 在射程内停下，发射追踪腐蚀液，对奶家人造成 35 点伤害 |
| 跳跃僵尸 | 快速移动，首次遇到阻挡时跳过角色，之后正常啃食；它是唯一能越过角色的敌人 |
| 僵尸王 | 4200 点耐久，交替召唤援军与投掷巨石；低于 40% 血量后暴怒并强化移动与技能频率 |

> 碰撞规则：除跳跃僵尸的一次跳跃外，所有僵尸必须吃掉同排的存活角色才能继续前进。移动层加入了越位保护，即使单帧移动距离过大，也不会穿过角色。

## 第三轮验证结果

- `game.js` 已通过 Node.js 语法检查，浏览器控制台无脚本错误。
- 原位大笑：演出容器与奶娃按钮的实测位置、宽高完全一致（9% × 19%，中心 x=62px）；背景色透明、无边框、无阴影、无圆角、无“捧腹大笑”标签，也不再出现铺满整行的“哈哈哈哈”横幅。
- 抠像效果：Canvas 四角 alpha 为 0，奶白肚皮和牙齿保持完整，底部白色地面残留已清理；每帧抠像在 176 × 243 画布上平均约 1.1ms。
- 视频生命周期：原视频保持未静音播放，暂停后画面与音频同时冻结，继续后恢复；重开、结算会停止播放并清空视频层与渲染循环。
- 单发验证：在无僵尸情况下模拟空闲 60 秒，四类远程角色计时器均停在 0；目标出现后的第一帧只产生 1 发毒液、1 发石头、1 发火焰和奶猴的 1 次双目标攻击（2 发），继续 21 帧没有补射或连发。
- 音效验证：奶鼠、奶蛇、奶猴、奶龙分别生成独立的噪声爆破与音调节点，音量与收集音效同级别；静音开关能阻止新音效触发。
- 第二轮回归记录：91 个移动碰撞场景 0 次穿越；完整五波模拟击退 82 个敌人；本轮未改动移动、碰撞与关卡逻辑。

## 素材说明

奶家人形象根据用户提供的附件裁切并抠图；奶娃静态图与捧腹大笑视频/原声来自用户提供素材，视频已裁掉手机界面并转为 H.264 / AAC 以提高浏览器兼容性。僵尸为配套生成的原创卡通素材，未直接使用植物大战僵尸原游戏素材。
