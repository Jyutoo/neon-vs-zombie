# 奶龙大战僵尸

一款以“奶家人”为主题的植物大战僵尸式网页塔防游戏。收集奶黄、放置奶蛋与十二生肖，守住五行奶家小院。

当前版本为 **电脑浏览器单关完整试玩版**，使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 启动游戏

- Windows：双击 `启动游戏.bat`。
- 也可以直接用浏览器打开 `index.html`。
- 如需本地服务，在项目目录运行 `python -m http.server 4173`，再访问 `http://127.0.0.1:4173`。

## 基本操作

1. 点击发光的奶黄，收集 25 点资源。
2. 点击左侧角色卡牌，再点击空草地放置。
3. 使用小铲子可以移除已放置的角色。
4. 点击每行最左侧的奶娃，可触发捧腹大笑并清空本行僵尸；僵尸突破时也会自动触发，每行限用一次。
5. 空格暂停或继续，数字 `1` / `2` 切换速度，`Esc` 或鼠标右键取消选择。

## 角色能力

| 角色 | 定位与能力 |
| --- | --- |
| 奶蛋 | 每 8 秒生成 25 奶黄 |
| 奶鼠 | 远程投掷石头，稳定单体输出 |
| 奶蛇 | 毒液命中后造成持续伤害 |
| 奶龙 | 范围火焰，对目标及附近僵尸造成伤害 |
| 奶兔 | 治疗自身及周围八格的伙伴 |
| 奶虎 | 高伤害、快速近战攻击 |
| 奶牛 | 900 点耐久，负责阻挡与近身顶撞 |
| 奶猴 | 每次攻击本行两个目标 |
| 奶羊 | 造成伤害并击退僵尸 |
| 奶马 | 中距离冲锋，造成伤害并撞退目标 |
| 奶鸡 | 提高本行其他奶家人 25% 攻击速度 |
| 奶猪 | 每 13 秒额外产出 25 奶黄 |
| 奶狗 | 吠叫减速本行僵尸，近身时撕咬 |
| 奶娃 | 每行一次，大笑清空本行僵尸 |
