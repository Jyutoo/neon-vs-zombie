# 奶龙大战僵尸

一款以"奶家人"为主题的网页游戏合集，包含经典塔防冒险模式与横版格斗闯关模式。收集奶黄、放置奶蛋与十二生肖，守住五行奶家小院；或操控奶龙在三段关卡中击败僵尸王，挑战无尽模式。

当前版本为 **无限关卡 + 奶币解锁版（第五轮优化）+ 主菜单与横版格斗模式**，使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 启动游戏

- Windows：双击 `启动游戏.bat`，打开主菜单。
- 也可以直接用浏览器打开 `index.html`（主菜单）。
- 如需本地服务，在项目目录运行 `python -m http.server 4173`，再访问 `http://127.0.0.1:4173`。

## 游戏模式

### 冒险模式（塔防）

从主菜单进入冒险模式，经典植物大战僵尸式塔防玩法。

**基本操作：**

1. 打开网页直接进入主页面：查看奶币余额、选择关卡、浏览角色图鉴并用奶币解锁角色。
2. 点击发光的奶黄收集资源：自然掉落为 25 点，奶蛋生产为 20 点。
3. 直接把左侧角色卡牌拖到草地即可种植；也可以沿用"点击卡牌，再点击空格子"的旧操作。未解锁角色会灰显，无法拖动或点选。
4. 拖动时合法格子会亮起黄色边框，占用、冷却、奶黄不足或拖出草地会显示红色提示，松手不会扣费。
5. 使用小铲子可以移除已放置的角色。
6. 点击每行最左侧的奶娃，会在奶娃原格内播放无白底、不缩放的捧腹大笑视频与原声：普通僵尸被清空，大块头与僵尸王只受到高额伤害；僵尸突破时也会自动触发，每行限用一次。
7. 空格暂停或继续，数字 `1` / `2` 切换速度，`Esc` 或鼠标右键取消选择或拖动；战斗顶栏可以随时返回主页。

### 奶龙战僵尸（横版格斗）

从主菜单选择「闯关模式」或「无尽模式」，进入 `action.html`。

**操作：**

| 按键 | 动作 |
| --- | --- |
| A / D 或方向键 | 左右移动 |
| 空格 | 跳跃（获得二段跳后可再跳一次） |
| J | 普攻三连（地面）/ 跳劈（空中） |
| K | 重击 |
| L | 喷火灼烧 |
| Shift | 冲刺（无敌帧） |
| Esc / P | 暂停 |
| 1 / 2 / 3 | 升级时选择强化 |

**闯关模式：** 三段清怪 → 僵尸王 Boss → 胜利结算。

**无尽模式：** 波次无限增强，每 5 波出现精英，每 10 波出现僵尸王。击杀获得经验，升级三选一强化。死亡后显示最佳记录。

## 关卡、奶币与解锁

- **无限关卡**：每一关固定五波，首通后解锁下一关。关卡数无上限，难度随关数持续上升。
- **波次**：五波基础数量为 `3 / 4 / 6 / 8 / 10`，每关再增加 `min(6, floor((关数 - 1) / 2))` 个僵尸；第 5、10、15……关的最后一波追加僵尸王。
- **敌人登场**：第 1 关只有普通与路障僵尸；第 2 关起加入快速僵尸，第 3 关起铁桶，第 4 关起跳跃，第 5 关起远程，第 6 关起大块头。每关阵容由固定种子生成，重复挑战时保持一致。
- **难度缩放**：僵尸血量为 `1.15^(关数 - 1)` 倍，移动速度最多提升到 1.35 倍，啃食与远程伤害最多提升到 1.8 倍；奶家人基础数值不变。
- **首通奖励**：`100 + (关数 - 1) * 50 + floor((关数 - 1) / 5) * 50` 奶币（第 1 关 100，第 5 关 300，第 10 关 600）。
- **重复挑战**：已通关关卡可再次挑战，获得首通奖励的 30%（至少 10 奶币），不重复推进关卡进度。
- **失败与退出**：失败不扣奶币，可无限重试；中途返回主页放弃本局进度，但不会损失已保存的奶币与解锁。
- **解锁价格**：奶鼠 100、奶兔 140、奶狗 160、奶虎 220、奶羊 240、奶鸡 260、奶猪 280、奶马 320、奶龙 380，全部解锁共需 2100 奶币。初始可用奶蛋、奶蛇、奶牛、奶猴。
- **存档**：奶币、累计获得、最高通关关数、当前选择关卡与已解锁角色保存在浏览器 `localStorage`，键名为 `nailong-vs-zombies-progress-v1`。主页提供二次确认的"重置进度"。

## 角色能力

所有角色的购买冷却在首版基础上统一增加 1 秒（奶蛋 5 秒、奶鼠 5 秒、奶蛇 7 秒、奶龙 11 秒、奶兔 9 秒、奶虎 9 秒、奶牛 11 秒、奶猴 8 秒、奶羊 9 秒、奶马 10 秒、奶鸡 10 秒、奶猪 9 秒、奶狗 8 秒）。

| 角色 | 定位与能力 |
| --- | --- |
| 奶蛋 | 每 12 秒生成 20 奶黄，成本 60 |
| 奶鼠 | 远程投掷石头，稳定单体输出 |
| 奶蛇 | 毒液命中后造成持续伤害，攻击时发出短促喷吐声 |
| 奶龙 | 范围火焰，对目标及附近僵尸造成伤害 |
| 奶兔 | 治疗自身及周围八格的伙伴 |
| 奶虎 | 高伤害、快速近战攻击，攻击时带有挥击声 |
| 奶牛 | 900 点耐久，负责阻挡与近身顶撞，攻击时带有低哞声 |
| 奶猴 | 每次攻击本行两个目标，发射果核时带有两声轻响 |
| 奶羊 | 造成伤害并击退僵尸；击退后目标获得抗性，不会立刻被连续弹开 |
| 奶马 | 中距离冲锋，造成伤害并撞退目标；同样受击退抗性保护 |
| 奶鸡 | 提高本行其他奶家人 25% 攻击速度 |
| 奶猪 | 每 13 秒额外产出 25 奶黄 |
| 奶狗 | 吠叫减速本行僵尸，近身时撕咬 |
| 奶娃 | 每行一次，在原位播放大笑视频与原声；普通僵尸秒杀，大块头受 650 伤害、僵尸王受 1400 伤害 |

> 击退机制：奶羊、奶马保留原有伤害与击退距离。僵尸第一次被弹开后获得 4 秒击退免疫，并持续免疫到它击杀当前阻挡角色为止；处于啃食状态的僵尸不会被弹开。这样僵尸能重新靠近并攻击奶羊或奶马，避免被永久锁在攻击距离外。

## 敌人能力

所有僵尸的移动速度在首版基础上降低约 10%：普通/路障 11、铁桶 9、快速 16、大块头 5.5、远程 8、跳跃 20、僵尸王 3.8。以上为第 1 关基础数值，后续关卡按难度倍率缩放血量、速度与伤害。

| 敌人 | 定位与能力 |
| --- | --- |
| 普通、路障、铁桶、快速僵尸 | 血量已提高约 25%，保留不同护甲与速度定位 |
| 大块头僵尸 | 1100 点耐久，移动缓慢；重击对目标造成 60 点伤害，并波及相邻角色 |
| 远程僵尸 | 在射程内停下，发射追踪腐蚀液，对奶家人造成 35 点伤害 |
| 跳跃僵尸 | 快速移动，首次遇到阻挡时跳过角色，之后正常啃食；它是唯一能越过角色的敌人 |
| 僵尸王 | 4200 点耐久，身体横跨相邻两行；交替召唤援军与投掷巨石，低于 40% 血量后暴怒并强化移动与技能频率 |

> 碰撞规则：除跳跃僵尸的一次跳跃外，所有僵尸必须吃掉同排的存活角色才能继续前进。移动层加入了越位保护，即使单帧移动距离过大，也不会穿过角色。

> 僵尸王双行规则：僵尸王以"上半行 + 下半行"的方式实体占据相邻两行，身体中心压在两行交界处。两行的奶家人都能锁定并攻击它，它也必须在吃掉任一行的挡路角色后才能继续前进；任一行奶娃大笑都能命中它，但同一次大笑只结算一次伤害。

> 倒地动画：僵尸被击杀后不会瞬间消失，而是以脚底为轴随机向左或向右倒下并淡出；普通僵尸 0.85 秒、大块头 1.05 秒、僵尸王 1.4 秒。倒地期间不再阻挡、攻击或计入存活，最后一个倒下动画播完才判定胜利。
