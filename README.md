# 奶家人的奇妙冒险

![奶家人的奇妙冒险：从庭院出发，向奶康挑战](docs/images/readme-banner.png)

从庭院出发，收集奶黄、布置防线，或操控奶娃亲自迎战奶康。使用原生 HTML、CSS、JavaScript，无需安装依赖或构建。

在线试玩: https://github.com/Jyutoo/neons-adventure

## 开始游戏

Windows 可双击 `启动游戏.bat`，也可直接打开 `src/index.html`。推荐在仓库根目录启动本地服务，避免浏览器对 `file://` 存档的限制：

```bash
python -m http.server 4173 --bind 127.0.0.1 --directory src
```

访问 <http://127.0.0.1:4173/>。存档按浏览器和访问来源隔离，在线版与本地版不会自动共享进度。

## 玩法与操作

首页提供两个并列入口：**庭院守护**与**亲自上阵**；右上角的**强化奶娃**用于永久强化。

| 玩法 | 内容 | 操作 |
| --- | --- | --- |
| 庭院守护（模式A） | 五行九列塔防，逐关解锁共 12 关，最后迎战奶康 | 拖动角色卡到草地，或先点卡再点格子；点击收集奶黄，小铲子移除角色，点击每行奶娃释放大笑 |
| 横版闯关（模式B） | 操控奶娃逐段清怪，每关包含 3–5 段战斗和奶康 Boss 战 | `A/D` 或左右方向键移动，`空格` 跳跃，`J` 普攻，`K` 重击，`L` 音波，`Shift` 冲刺 |
| 横版无尽（模式B） | 挑战不断增强的波次，击杀升级、三选一强化，刷新最佳记录 | 战斗操作同横版闯关；升级时按 `1/2/3` 选择 |

塔防按 `空格` 暂停/继续，`1/2` 切换倍速，`Esc` 或右键取消选择；横版按 `Esc/P` 暂停。横版跳跃可以躲避部分攻击，音波命中高度也随角色变化。

## 奶黄、解锁与存档

- **奶黄共用**：塔防与强化页使用同一全局余额。塔防开局至少有 150 奶黄；退出保留本局收支，通关额外获得奖励。战斗期间在另一标签页购买强化，其消费不会被塔防退出或结算覆盖。
- **角色解锁靠塔防**：初始可用奶蛋、奶蛇、奶牛、奶猴，其余角色随塔防通关解锁；已拥有的角色永久保留。
- **横版关卡解锁靠无尽**：初始开放第 1 关，无尽最佳每提高 3 波，多解锁一关，最多 12 关。闯关通关不会解锁下一关，选关页会显示下一解锁目标。
- **永久强化**：13 个角色方向各有 7 级，费用依次为 `100 / 200 / 400 / 800 / 1600 / 3200 / 6400` 奶黄。效果跨模式生效，并与横版局内升级叠加，详情见强化页。
- **本机自动保存**：保存奶黄、两种模式的最高通关记录、塔防选关、角色、无尽最佳与强化等级。旧版存档自动迁移；清除浏览器站点数据会丢失进度，塔防选关页提供带确认的重置操作。

## 开发

| 位置 | 职责 |
| --- | --- |
| `src/*.html`、`src/css/` | 页面与样式 |
| `src/js/game.js` | 塔防与选关 |
| `src/js/action.js` | 横版战斗 |
| `src/js/action-data.js`、`src/js/action-logic.js` | 横版数值与纯逻辑 |
| `src/js/progress.js` | 共用存档、迁移与归一化 |
| `src/js/menu.js`、`src/js/action-levels.js`、`src/js/upgrade.js` | 菜单、横版选关与强化 |
| `src/assets/` | 角色、敌人、音视频与原始素材 |
| `tests/` | Node 内置测试；DOM helper 加载真实生产脚本 |
| `tools/`、`docs/` | 开发期素材工具与设计文档 |

需要 Node.js 运行测试；游戏本身不依赖 Node.js：

```bash
node --test tests/*.test.js
node --check src/js/game.js
```

修改逻辑先写失败测试，每次更新记录到 `CHANGELOG.md`。文件职责、视觉约定与关键约束见 [AGENTS.md](AGENTS.md)。

## 素材与限制

角色、敌人立绘及奶娃音视频基于用户提供的素材加工，原始素材保留在 `src/assets/source-*` 与 `src/assets/source-enemies/`。首页使用绿色庭院背景；宣传图位于 `docs/images/`。

当前主要面向电脑鼠标与键盘。首页、选关和强化页已有窄屏布局，战斗尚未完整支持手机；横版舞台为 1280×720，窄窗口仍存在偏移问题。
