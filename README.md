# 奶龙大战僵尸

以"奶家人"为主题的网页游戏合集，包含**模式A 塔防**与**模式B 横版格斗**两套玩法，外加一套跨模式生效的**奶娃强化系统**。三者共用一份全局存档与一种全局货币"奶黄"。

使用原生 HTML、CSS 和 JavaScript，无需安装依赖、没有构建步骤。

当前版本：**全局奶黄经济 + 12 关塔防 + 12 关格斗 + 持久强化（v1.2）**

## 启动游戏

- Windows：双击 `启动游戏.bat`，直接打开主菜单。
- 或直接用浏览器打开 `src/index.html`（全部代码都在 `src/` 下）。
- 建议走本地服务（`localStorage` 在 `file://` 下部分浏览器受限）：

  ```bash
  python -m http.server 4173 --bind 127.0.0.1
  # 访问 http://127.0.0.1:4173/src/index.html
  ```

## 模式A：塔防

经典五行九列玩法，把奶家人种进庭院挡住僵尸。

**操作**

1. 在关卡选择页挑选关卡，点击开始进入战斗。
2. 点击发光的奶黄收集资源：自然掉落 25 点，奶蛋每次 20 点、奶猪每次 25 点。
3. 把左侧角色卡拖到草地即可种植，也支持"点卡牌 → 点空格"。未解锁角色灰显，无法拖动或点选。
4. 拖动时合法格子亮黄框；占用、冷却中、奶黄不足或拖出草地显示红框，松手不扣费。
5. 小铲子移除已放置的角色。
6. 点击每行最左侧的奶娃，在原格播放无白底、不缩放的捧腹大笑视频与原声：普通僵尸被清空，大块头受 650 伤害、僵尸王受 1400 伤害；僵尸突破时也会自动触发，每行限一次。
7. `空格` 暂停/继续，`1` / `2` 切换倍速，`Esc` 或右键取消选择与拖动，战斗顶栏随时返回主页。

**关卡**

固定 12 关，逐关解锁，第 12 关为 BOSS 关。

| 关数 | 波数 | 难度标签 |
| --- | --- | --- |
| 1–3 | 5 | 入门 |
| 4–6 | 6 | 进阶 |
| 7–9 | 7 | 中级 |
| 10–11 | 8 | 高级 |
| 12 | 10 | BOSS 关 |

每波基础数量为 `3 + floor(波序号 × 1.2)`；前两波不出现大块头。阵容以 `level * 7919 + 13` 为种子生成，重复挑战时保持一致。

**敌人登场**：第 1 关普通与路障；第 2 关起快速，第 3 关起铁桶，第 4 关起跳跃，第 5 关起远程，第 6 关起大块头；第 12 关最后一波追加僵尸王。

**奖励**：首通 `50 + (关数 - 1) × 15` 奶黄；重复通关给 30%（至少 10）。失败不发奖也不扣款。

### 角色能力

| 角色 | 定位与能力 |
| --- | --- |
| 奶蛋 | 每 12 秒生成 20 奶黄，成本 60 |
| 奶鼠 | 远程投掷石头，稳定单体输出 |
| 奶蛇 | 毒液命中后造成 4 秒持续伤害 |
| 奶龙 | 范围火焰，对目标及附近僵尸造成伤害 |
| 奶兔 | 每 3 秒治疗自身及周围八格伙伴 24 点耐久 |
| 奶虎 | 高伤害、快速近战 |
| 奶牛 | 900 点耐久，阻挡并近身顶撞 |
| 奶猴 | 每次攻击本行两个目标 |
| 奶羊 | 头槌造成伤害并击退，击退后目标获得抗性 |
| 奶马 | 中距离冲锋，撞退目标，同受抗性保护 |
| 奶鸡 | 提高本行其他奶家人 25% 攻击速度 |
| 奶猪 | 每 13 秒拱出 25 奶黄，耐久高于奶蛋 |
| 奶狗 | 吠叫减速本行僵尸，近身时撕咬 |
| 奶娃 | 每行一次，原位大笑；普通僵尸秒杀，大块头 650、僵尸王 1400 |

> 击退机制：僵尸第一次被弹开后获得 4 秒击退免疫，并持续到它击杀当前阻挡角色为止；啃食中的僵尸不会被弹开。这样奶羊、奶马不会把僵尸永久锁在攻击距离外。

### 敌人能力

| 敌人 | 定位与能力 |
| --- | --- |
| 普通、路障、铁桶、快速僵尸 | 各有不同护甲与速度定位 |
| 大块头僵尸 | 1100 点耐久，移动缓慢；重击造成 60 点伤害并波及相邻角色 |
| 远程僵尸 | 在射程内停下，发射追踪腐蚀液，造成 35 点伤害 |
| 跳跃僵尸 | 快速移动，首次遇到阻挡时跳过角色，之后正常啃食；唯一能越过角色的敌人 |
| 僵尸王 | 4200 点耐久，身体横跨相邻两行；交替召唤援军与投掷巨石，低于 40% 血量后暴怒 |

> 碰撞规则：除跳跃僵尸的一次跳跃外，所有僵尸必须吃掉同排的存活角色才能继续前进。移动层有越位保护，单帧移动距离过大也不会穿过角色。

> 僵尸王双行规则：它以"上半行 + 下半行"实体占据相邻两行，中心压在交界处。两行的奶家人都能锁定并攻击它，它也必须在吃掉任一行挡路角色后才能前进；任一行奶娃大笑都能命中，但同一次大笑只结算一次伤害。

> 倒地动画：僵尸被击杀后以脚底为轴向随机方向倒下并淡出（普通 0.85 秒、大块头 1.05 秒、僵尸王 1.4 秒）。倒地期间不再阻挡、攻击或计入存活，最后一个倒地动画播完才判定胜利。

## 模式B：横版格斗

操控**奶娃**在横版战场中逐段清怪，最后击败僵尸王。

| 按键 | 动作 |
| --- | --- |
| A / D 或方向键 | 左右移动 |
| 空格 | 跳跃（获得二段跳后可再跳一次） |
| J | 普攻三连（地面）/ 跳劈（空中） |
| K | 重击 |
| L | 音波 |
| Shift | 冲刺（无敌帧） |
| Esc / P | 暂停 |
| 1 / 2 / 3 | 升级时选择强化 |

**闯关**：12 关，每一关都由 `levelConfig(level)` 按关卡现算，配置互不相同。第 1 关是 3 段战斗 + 僵尸王；每满 4 级多一段战场、并给每个批次多 1 只怪，第 12 关为 5 段战斗 + 僵尸王。同级别内的成长：怪物血量 `+10%/级`、伤害 `+5%/级`、速度 `+2%/级`（上限 1.35 倍），僵尸王血量 `+15%/级`（第 1 关 1200 → 第 12 关 3180）。逐段清怪后才推进，最后一段固定为 Boss 战。

**无尽**：波次无限增强，每 5 波出精英，每 10 波出僵尸王。击杀得经验，升级三选一，死亡后显示最佳记录。缩放为血量 `+8%/波`、伤害 `+5%/波`、速度 `+2%/波`（上限 1.4 倍），单波数量上限 12，Boss 每次登场血量 `+30%`。

**空中闪避**：命中判定同时检查水平距离与身体纵向重叠，跳起来可以躲过僵尸普攻与僵尸王冲撞；震荡波按是否着地判定。跳跃最高点约 138px，需要一次完整跳跃而不是轻点。玩家的音波命中框同样跟随自身高度，跳起后音波会打不到地面的僵尸。

**局内肉鸽升级池**（11 项，每级 3 选 1，经验需求 `30 + 20 × (等级 - 1)`）：
奶香重拳、铁头功、音波强化、深呼吸、灵活走位、奶量充足、越战越勇、二段跳（唯一）、空中霸主、冲刺大师、连击大师。

## 奶娃强化系统

主菜单进入 `src/upgrade.html`，消耗全局奶黄为 13 个方向各自升到 7 级。**强化效果同时作用于模式A 与模式B**，与局内肉鸽升级互不冲突、叠加生效。

费用逐级为 `100 / 200 / 400 / 800 / 1600 / 3200 / 6400` 奶黄。

| 角色 | 模式A 效果 | 模式B 效果 |
| --- | --- | --- |
| 奶蛋 | +使用次数（每级 +1 次） | +自动回复（每级 +1 HP/秒） |
| 奶鼠 / 奶兔 / 奶鸡 | -使用冷却 10%/级 | -技能冷却 10%/级 |
| 奶蛇 / 奶龙 | +持续伤害 20%/级 | +持续伤害 20%/级 |
| 奶虎 / 奶牛 / 奶猴 | +攻击力 15%/级 | +攻击力 15%/级 |
| 奶羊 / 奶马 | +同行回血 10 HP/级 | +杀敌回血 2 HP/级 |
| 奶猪 / 奶狗 | +同行盾牌 20 HP/级 | +盾牌 30 HP/级 |

## 奶黄与解锁

**奶黄是唯一的货币**，全局持久保存，不再有单独的"奶币"。

- 进入模式A 时，全局余额直接作为开局资源（保底 150，防止破产后无法布阵）。
- 结算时把本局剩余奶黄加上通关奖励写回全局余额；中途返回主页同样带回剩余，但不再发通关奖励。
- 强化页消费直接扣全局余额。

**解锁**

- 模式A 角色：初始可用奶蛋、奶蛇、奶牛、奶猴（4 / 13），其余按通关关卡自动解锁——奶鼠 2、奶兔 3、奶狗 4、奶虎 5、奶羊 6、奶鸡 7、奶猪 8、奶马 9、奶龙 10。
- 模式B 关卡：`min(12, floor(无尽最佳波数 / 3) + 1)`。**推无尽是解锁一切的引擎。**

**存档**：`localStorage` 键名 `nailong-vs-zombies-progress-v2`，保存奶黄余额、累计获得、最高通关、选择关卡、解锁列表、无尽最佳记录与强化等级。旧的 `...-v1` 存档自动迁移，数据损坏时回退默认档。主页提供二次确认的"重置进度"。

## 开发与测试

```bash
node --test tests/*.test.js          # 132 项单元测试（10 个文件）
node --check src/js/game.js          # 逐个 JS 文件做语法检查（脚本都在 src/js/）
```

改逻辑遵循"先在 `tests/` 写失败用例 → 实现 → 全绿"的顺序；可独立计算的规则放进无 DOM 的纯逻辑模块，页面脚本只做编排与渲染。每次更新必须在 `CHANGELOG.md` 追加记录。详见 [AGENTS.md](AGENTS.md)。

## 素材说明

奶家人形象由用户提供素材裁切抠图；奶娃静态图与捧腹大笑视频/原声取自用户素材，视频直接用微信原片（592×1280 手机录屏，H.264 / AAC），画面里的状态栏与"停止"按钮由 `game.js` 的 `BABY_VIDEO_CROP` 在播放时裁掉。僵尸为配套生成的原创卡通素材，未直接使用《植物大战僵尸》原游戏素材。`src/assets/source-*` 是裁切抠图用的原始素材副本，代码不引用但有意保留。
