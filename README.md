# 奶龙大战僵尸

一款以“奶家人”为主题的植物大战僵尸式网页塔防游戏。收集奶黄、放置奶蛋与十二生肖，守住五行奶家小院。

当前版本为 **电脑浏览器单关完整试玩版（第四轮优化）**，使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 启动游戏

- Windows：双击 `启动游戏.bat`。
- 也可以直接用浏览器打开 `index.html`。
- 如需本地服务，在项目目录运行 `python -m http.server 4173`，再访问 `http://127.0.0.1:4173`。

## 基本操作

1. 点击发光的奶黄收集资源：自然掉落为 25 点，奶蛋生产为 20 点。
2. 直接把左侧角色卡牌拖到草地即可种植；也可以沿用“点击卡牌，再点击空格子”的旧操作。
3. 拖动时合法格子会亮起黄色边框，占用、冷却、奶黄不足或拖出草地会显示红色提示，松手不会扣费。
4. 使用小铲子可以移除已放置的角色。
5. 点击每行最左侧的奶娃，会在奶娃原格内播放无白底、不缩放的捧腹大笑视频与原声：普通僵尸被清空，大块头与僵尸王只受到高额伤害；僵尸突破时也会自动触发，每行限用一次。
6. 空格暂停或继续，数字 `1` / `2` 切换速度，`Esc` 或鼠标右键取消选择或拖动。

## 角色能力

所有角色的购买冷却在首版基础上统一增加 1 秒（奶蛋 5 秒、奶鼠 5 秒、奶蛇 7 秒、奶龙 11 秒、奶兔 9 秒、奶虎 9 秒、奶牛 11 秒、奶猴 8 秒、奶羊 9 秒、奶马 10 秒、奶鸡 10 秒、奶猪 9 秒、奶狗 8 秒）。

| 角色 | 定位与能力 |
| --- | --- |
| 奶蛋 | 每 12 秒生成 20 奶黄，成本 60 |
| 奶鼠 | 远程投掷石头，稳定单体输出 |
| 奶蛇 | 毒液命中后造成持续伤害，攻击时发出短促喷吐声 |
| 奶龙 | 范围火焰，对目标及附近僵尸造成伤害 |
| 奶兔 | 治疗自身及周围八格的伙伴 |
| 奶虎 | 高伤害、快速近战攻击，攻击时带有挥击声 |
| 奶牛 | 900 点耐久，负责阻挡与近身顶撞，攻击时带有低哞声 |
| 奶猴 | 每次攻击本行两个目标，发射果核时带有两声轻响 |
| 奶羊 | 造成伤害并击退僵尸；击退后目标获得抗性，不会立刻被连续弹开 |
| 奶马 | 中距离冲锋，造成伤害并撞退目标；同样受击退抗性保护 |
| 奶鸡 | 提高本行其他奶家人 25% 攻击速度 |
| 奶猪 | 每 13 秒额外产出 25 奶黄 |
| 奶狗 | 吠叫减速本行僵尸，近身时撕咬 |
| 奶娃 | 每行一次，在原位播放大笑视频与原声；普通僵尸秒杀，大块头受 650 伤害、僵尸王受 1400 伤害 |

> 击退机制：奶羊、奶马保留原有伤害与击退距离。僵尸第一次被弹开后获得 4 秒击退免疫，并持续免疫到它击杀当前阻挡角色为止；处于啃食状态的僵尸不会被弹开。这样僵尸能重新靠近并攻击奶羊或奶马，避免被永久锁在攻击距离外。

## 敌人能力

所有僵尸的移动速度在首版基础上降低约 10%：普通/路障 11、铁桶 9、快速 16、大块头 5.5、远程 8、跳跃 20、僵尸王 3.8。

| 敌人 | 定位与能力 |
| --- | --- |
| 普通、路障、铁桶、快速僵尸 | 血量已提高约 25%，保留不同护甲与速度定位 |
| 大块头僵尸 | 1100 点耐久，移动缓慢；重击对目标造成 60 点伤害，并波及相邻角色 |
| 远程僵尸 | 在射程内停下，发射追踪腐蚀液，对奶家人造成 35 点伤害 |
| 跳跃僵尸 | 快速移动，首次遇到阻挡时跳过角色，之后正常啃食；它是唯一能越过角色的敌人 |
| 僵尸王 | 4200 点耐久，身体横跨相邻两行；交替召唤援军与投掷巨石，低于 40% 血量后暴怒并强化移动与技能频率 |

> 碰撞规则：除跳跃僵尸的一次跳跃外，所有僵尸必须吃掉同排的存活角色才能继续前进。移动层加入了越位保护，即使单帧移动距离过大，也不会穿过角色。

> 僵尸王双行规则：僵尸王以“上半行 + 下半行”的方式实体占据相邻两行，身体中心压在两行交界处。两行的奶家人都能锁定并攻击它，它也必须在吃掉任一行的挡路角色后才能继续前进；任一行奶娃大笑都能命中它，但同一次大笑只结算一次伤害。

> 倒地动画：僵尸被击杀后不会瞬间消失，而是以脚底为轴随机向左或向右倒下并淡出；普通僵尸 0.85 秒、大块头 1.05 秒、僵尸王 1.4 秒。倒地期间不再阻挡、攻击或计入存活，最后一个倒下动画播完才判定胜利。

## 第四轮验证结果

- `game.js` 已通过 Node.js 语法检查，浏览器控制台无脚本错误与警告。
- 拖动种植：真实鼠标拖动奶蛋到空格后成功扣费 60 并进入 5 秒冷却；幽灵图、落点高亮与拖动样式在松手后完全清理；拖拽结束后不会误触发卡牌选中或落点点击，旧的点选种植流程仍可用。
- 非法拖动：格子已占用、卡牌冷却中、奶黄不足、拖出草地均显示对应红色提示与文案，松手不扣费、不放置。
- 倒地动画：普通僵尸死亡后播放 0.85 秒 `zombieFall`，血条立即隐藏，重复伤害不会重复计击杀；动画结束后从数组与 DOM 清理。大块头 1.05 秒、僵尸王 1.4 秒。
- 僵尸王双行：分别以第 4/5 行和第 1/2 行出生测试，上下两行植物都能锁定并命中 Boss；Boss 会啃食任一行的挡路角色，清空阻挡后才继续前进；Boss 血条正常显示。
- 大笑分级：普通僵尸被秒杀并倒地；大块头 1100 → 450、僵尸王 4200 → 2800 且继续前进，伤害数字与状态栏提示正确；已残血的大怪可被补刀，第二行大笑可继续把 Boss 打到 1400。
- 自动触发：Boss 覆盖的两行奶娃按顺序自动触发，伤害各结算一次；普通僵尸自动大笑同样走倒地动画。
- 胜利时序：最后一个僵尸进入倒地状态时游戏仍继续，动画清理后才弹出胜利结算；重开会清空残留尸体元素。
- 关卡回归：30 株完整防线在 36 秒内分别击杀两种出生行的僵尸王，剩余 30 株、未使用奶娃，Boss 不因双行判定变得无法击杀。
- 第二轮/第三轮回归：原位大笑的位置与抠像、远程单发节奏、攻击音效、击退抗性均保持正常。
