# 奶龙大战僵尸 - 大型重构设计文档

> **版本**: 1.0  
> **日期**: 2026-10-25  
> **状态**: 待实现

---

## 1. 概述

本次重构将彻底改变游戏的经济系统、关卡结构和角色体系，引入持久化强化系统，使两种游戏模式形成有机联动。

### 1.1 核心变更
- **货币统一**：奶黄成为唯一全局持久货币
- **关卡固定**：模式A和模式B各12关
- **主角替换**：模式B奶龙→奶娃
- **强化系统**：13方向×7级，跨模式生效
- **解锁重构**：无尽模式驱动关卡解锁

---

## 2. 货币系统重构

### 2.1 移除奶币
- 删除所有奶币相关代码和UI
- 删除奶币存档字段

### 2.2 奶黄持久化
**当前行为**：
- 每关开始给150奶黄
- 关卡结束后清零

**新行为**：
- 奶黄跨关卡保留
- 关卡开始不再自动给奶黄（或给少量初始值，待测试）
- 奶黄用于：
  - 模式A：种植角色
  - 强化系统：升级奶娃能力

### 2.3 存档结构变更
```javascript
// 旧结构
{
  coins: 100,           // 奶币（删除）
  totalEarned: 100,     // 累计获得（删除）
  highestCleared: 1,    // 最高通关（保留）
  selectedLevel: 1,     // 选择关卡（保留）
  unlocked: ['egg', ...] // 已解锁角色（保留）
}

// 新结构
{
  custard: 500,         // 奶黄（新增，全局货币）
  highestCleared: 1,    // 模式A最高通关
  actionHighestCleared: 1, // 模式B最高通关
  endlessBest: 3,       // 无尽模式最佳波次
  unlocked: ['egg', ...], // 已解锁角色
  upgrades: {           // 强化等级（新增）
    egg: 2,             // 奶蛋强化等级
    rat: 1,             // 奶鼠强化等级
    // ... 其他角色
  }
}
```

## 3. 关卡系统

### 3.1 模式A（塔防）- 12关
**当前**：5关（第5关BOSS）  
**目标**：12关，难度递增

**关卡结构**：
| 关卡 | 波数 | 敌人类型 | 特殊 |
|------|------|---------|------|
| 1-3 | 5波 | 基础僵尸 | 入门 |
| 4-6 | 6波 | +路障/快速 | 进阶 |
| 7-9 | 7波 | +铁桶/跳跃 | 中级 |
| 10-11 | 8波 | +大块头/远程 | 高级 |
| 12 | 10波 | 全类型+僵尸王 | 最终BOSS |

**难度缩放**：
- 僵尸血量：`1.15^(关卡-1)` 倍
- 僵尸速度：最多1.35倍
- 僵尸伤害：最多1.8倍

**奖励**：
- 首通：固定奶黄奖励（待测试，建议50-200递增）
- 重复：首通的30%（至少10）
- 失败：不扣奶黄

### 3.2 模式B（闯关）- 12关
**当前**：3段清怪+BOSS  
**目标**：12关，每关独立

**关卡选择界面**：
- 类似模式A的关卡轨道
- 显示关卡编号、难度、奖励
- 已通关/待挑战/未解锁状态

**每关结构**：
- 保持当前3段式（3屏清怪+BOSS）
- 或改为多波敌人（待确认）

**解锁规则**：
- 模式B无尽模式每3波解锁一关
- 初始解锁第1关

## 4. 角色替换

### 4.1 奶娃设计
**素材**：`assets/baby-glance.png`  
**动作**：
- 移动（左右）

| 原奶龙 | 新奶娃 |

## 5. 强化系统

### 5.1 系统概述
- **入口**：主菜单新增"强化奶娃"按钮
- **界面**：奶娃形象 + 13个强化方向
- **货币**：奶黄
- **等级**：每个方向最多7级
- **消耗**：100 → 200 → 400 → 800 → 1600 → 3200 → 6400

### 5.2 强化方向与效果

**模式A强化效果**：
| 角色 | 强化效果 | 每级数值（示例） |
|------|---------|----------------|
| 奶蛋 | +奶娃使用次数 | +1次/级 |
| 奶鼠/奶兔/奶鸡 | -奶娃使用冷却 | -10%/级 |
| 奶牛/奶虎/奶猴 | +奶娃APK | +15%/级 |
| 奶龙/奶蛇 | +持续伤害 | +20%/级 |
| 奶马/奶羊 | +同行奶家卡回血 | +10HP/级 |
| 奶狗/奶猪 | +同行奶家卡临时盾牌 | +20HP/级 |

**模式B强化效果**：
| 角色 | 强化效果 | 每级数值（示例） |
|------|---------|----------------|
| 奶蛋 | +奶娃自动回复 | +1HP/秒/级 |
| 奶鼠/奶兔/奶鸡 | -奶娃技能冷却 | -10%/级 |
| 奶牛/奶虎/奶猴 | +奶娃APK | +15%/级 |
| 奶龙/奶蛇 | +持续伤害 | +20%/级 |
| 奶马/奶羊 | +杀敌回血 | +2HP/级 |
| 奶狗/奶猪 | +盾牌 | +30HP/级 |

### 5.3 强化界面设计
```
┌─────────────────────────────────────┐
│  强化奶娃                    奶黄:500 │
├─────────────────────────────────────┤
│                                     │
│         [奶娃形象]                  │
│                                     │
│  强化方向（13个卡片）               │
│  ┌────┐ ────┐ ┌────┐              │
│  │奶蛋│ │奶鼠│ │奶蛇│  ...         │
│  │Lv.2│ │Lv.1│ │Lv.0│              │
│  │200 │ │100 │ │锁定│              │
│  └────┘ └────┘ └────┘              │
│                                     │
│  [返回]  [强化]                     │
└─────────────────────────────────────┘
```

### 5.4 强化生效规则
- **持久化强化**：强化等级保存在存档，跨关卡、跨模式生效
- **单局肉鸽**：模式B的肉鸽升级仍然保留，但只在单局生效
- **叠加规则**：持久化强化 × 肉鸽强化（乘法叠加）

## 6. 解锁逻辑重构

### 6.1 角色解锁
**当前**：奶币解锁  
**新规则**：通关模式A关卡解锁

| 角色 | 解锁条件 |
|------|---------|
| 奶蛋/奶蛇/奶牛/奶猴 | 初始可用 |
| 奶鼠 | 通关模式A第2关 |
| 奶兔 | 通关模式A第3关 |
| 奶狗 | 通关模式A第4关 |
| 奶虎 | 通关模式A第5关 |
| 奶羊 | 通关模式A第6关 |
| 奶鸡 | 通关模式A第7关 |
| 奶猪 | 通关模式A第8关 |
| 奶马 | 通关模式A第9关 |
| 奶龙 | 通关模式A第10关 |

### 6.2 关卡解锁
**规则**：模式B无尽模式波次驱动

| 模式B无尽波次 | 解锁模式A关卡 | 解锁模式B关卡 |
|--------------|--------------|--------------|
| 初始 | 第1关 | 第1关 |
| 第3波 | 第2关 | 第2关 |
| 第6波 | 第3关 | 第3关 |
| 第9波 | 第4关 | 第4关 |
| ... | ... | ... |
| 第33波 | 第12关 | 第12关 |

**公式**：
```javascript
unlockedLevel = Math.floor(endlessBestWave / 3) + 1;
// 例：无尽最佳3波 → 解锁第2关
// 例：无尽最佳9波 → 解锁第4关
```
