# 奶龙大战僵尸：主菜单与「奶龙战僵尸」模式设计

日期：2026-10-24
状态：待用户审阅
分支：dev

## 1. 背景与目标

现有项目是一个单页塔防游戏（`index.html` + `styles.css` + `game.js`），只有一关五波的塔防玩法，进入页面直接弹开始说明。

本次新增：

1. 类似初代《植物大战僵尸》的主菜单：标题画面、模式选择、玩法说明。
2. 新玩法「奶龙战僵尸」：单线横版格斗闯关，包含三段关卡 + Boss，另有无尽模式与局内肉鸽升级。

不改变现有塔防玩法的核心逻辑与数值。

## 2. 非目标

- 不做手机/触屏适配，沿用桌面端（`min-width: 1024px`）。
- 不做联机、排行榜、账号系统。
- 不新增塔防关卡。
- 不引入任何框架或第三方依赖。
- 不新增图片素材；Boss 与精英怪通过现有素材 + CSS 表现。

## 3. 文件结构

```text
index.html                 主菜单（重写）
menu.css                   主菜单样式
menu.js                    主菜单交互（模式弹层、帮助、最佳记录）
game.html                  原塔防页面（由现 index.html 迁移）
game.js                    原塔防逻辑（不改逻辑）
styles.css                 原塔防样式（仅补少量链接/图标样式）
action.html                奶龙战僵尸页面
action.css                 奶龙模式样式
action-data.js             奶龙模式数值配置（玩家、敌人、Boss、强化、波次）
action.js                  奶龙模式逻辑（状态机、战斗、镜头、升级、结算）
assets/                    现有素材，全部复用
启动游戏.bat                不变，仍打开 index.html
README.md                  更新项目结构与玩法说明
```

### 页面导航

- `index.html` → 冒险模式 → `game.html`
- `index.html` → 奶龙战僵尸 → `action.html?mode=level` 或 `action.html?mode=endless`
- 塔防页与奶龙页均有「返回主菜单」入口，回到 `index.html`。
- 页面间不共享内存状态，仅通过 `localStorage` 共享无尽最佳记录。
- `mode` 参数缺省或非法时回退为 `level`。

### 脚本约定

- 每个页面脚本使用 IIFE 隔离作用域，不污染全局（`action-data.js` 只暴露 `window.ACTION_DATA`）。
- `game.js` 保持现有全局写法，不重构。
- 所有 JS 通过 `node --check`。

## 4. 主菜单

### 4.1 画面结构

- 全屏奶家小院背景：渐变天空、漂移云层、栅栏、草地，全部 CSS 绘制。
- 中央标题区：奶龙头像 + 主标题「奶龙大战僵尸」+ 副标题「奶家小院保卫战」。
- 标题左右放奶龙、僵尸立绘，带上下浮动待机动画。
- 模式区两块木牌式大按钮，尺寸约 380×220：

| 入口 | 文案 | 行为 |
| --- | --- | --- |
| 冒险模式 | 种植十二生肖，守住五行小院 | 跳转 `game.html` |
| 奶龙战僵尸 | 亲自上阵，打穿僵尸潮 | 打开模式弹层 |

- 底部：`玩法说明` 按钮、版本号 `v1.1 · 原生 HTML / CSS / JS`。

### 4.2 模式弹层

- 点击「奶龙战僵尸」后弹出居中面板，提供两个按钮：
  - **闯关模式**：三段关卡 + 僵尸王 Boss，跳转 `action.html?mode=level`。
  - **无尽模式**：波次无限增强；下方显示本机最佳「第 X 波」，没有记录时显示「暂无记录」。跳转 `action.html?mode=endless`。
- `Esc`、点击遮罩、右上角关闭按钮均可关闭弹层。

### 4.3 玩法说明弹层

分两块说明：

- 冒险模式：收集奶黄、种植角色、奶娃清行、快捷键。
- 奶龙战僵尸：`A/D` 移动、`空格` 跳跃、`J` 普攻、`K` 重击、`L` 喷火、`Shift` 冲刺、`Esc` 暂停；击杀升级、三选一强化；闯关与无尽规则。

### 4.4 交互与视觉

- 按钮悬停上浮 6px、阴影加深；点击有 0.15s 按下反馈。
- 云层 40s 循环漂移，角色 2.4s 上下浮动。
- 键盘可用 Tab 聚焦，按钮有 `:focus-visible` 描边。
- 主菜单不播放音频。

### 4.5 最佳记录读取

- key：`nailong.action.endlessBest`，值：`{"wave":12,"kills":86,"date":"2026-10-24"}`。
- 读取包在 `try/catch` 中，`localStorage` 不可用时静默降级为「暂无记录」。

## 5. 奶龙战僵尸模式

### 5.1 舞台与镜头

- 内部逻辑分辨率固定 1280×720，页面按宽度等比缩放，保持 16:9。
- 地面线 `GROUND_Y = 560`，角色脚底贴地。
- 闯关模式世界宽度 5120，分为 4 屏：
  - 第 1 屏：x 0–1280
  - 第 2 屏：x 1280–2560
  - 第 3 屏：x 2560–3840
  - Boss 庭院：x 3840–5120
- 镜头水平跟随玩家，限制在世界范围内；战斗段镜头锁定在当前屏，清怪后解锁。
- 背景视差：天空 0.15、云 0.3、栅栏 0.6、灌木 0.85、地面 1.0。
- 无尽模式固定 1280 宽单屏，镜头不动，玩家活动范围 x 60–1220。

### 5.2 渲染方式

- 使用 DOM + CSS transform 渲染，不使用 Canvas。
- 图层从后到前：背景、敌人、奶龙、特效、HUD。
- 实体 DOM 用 `Map<id, element>` 复用，死亡、重开、换模式时彻底移除，避免节点泄漏。
- 实体位置通过 `translate3d(x, y, 0)` 更新。
- 特效元素（伤害数字、尘土、火舌、震波）最多同时 40 个，超出时移除最早的。

### 5.3 玩家

基础属性：

| 属性 | 数值 |
| --- | --- |
| 最大生命 | 100 |
| 移动速度 | 300 px/s |
| 跳跃初速度 | -780 px/s |
| 重力 | 2200 px/s² |
| 受击无敌 | 0.7s |
| 冲刺 | 700 px/s，持续 0.16s，无敌 0.25s，冷却 2s |

操作：

| 按键 | 行为 |
| --- | --- |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格` | 跳跃；拥有二段跳强化后可再跳一次 |
| `J` | 普攻；地面三段连击，空中为跳劈 |
| `K` | 重击，击退并造成硬直 |
| `L` | 喷火，扇形范围伤害 + 灼烧 |
| `Shift` | 冲刺，短暂无敌 |
| `Esc` / `P` | 暂停/继续 |

普攻三段：

| 段数 | 伤害 | 前摇 | 后摇 | 范围 | 击退 |
| --- | --- | --- | --- | --- | --- |
| 第一段 | 14 | 0.08s | 0.16s | 85px | 40 |
| 第二段 | 14 | 0.08s | 0.16s | 85px | 40 |
| 第三段 | 24 | 0.12s | 0.24s | 100px | 110 |

- 连击窗口：一段结束后 0.55s 内按 `J` 接下一段，超时重置。
- 第三段命中触发轻微屏幕震动。
- 空中按 `J`：跳劈，伤害 30，范围 90px，落地时小范围尘土特效。

重击：

- 伤害 32，范围 100px，前摇 0.18s，后摇 0.3s，击退 150，冷却 0.9s。

喷火：

- 范围 240px、上下张开约 44° 的扇形，伤害 45，附加 4 秒灼烧（每秒 3 点）。
- 冷却 6s，起手 0.2s，期间可被攻击。

冲刺：

- 0.16s 内水平位移，期间无敌；结束后进入 2s 冷却；不能穿过屏幕边界。

受击与死亡：

- 受击后 0.7s 无敌并闪烁；生命归零进入失败结算。
- 跳跃支持 0.1s coyote time 与 0.12s 跳跃缓冲。

连击计数：

- 每次命中敌人连击 +1，2 秒内无命中则清零；HUD 显示当前连击，结算记录最高连击。

### 5.4 敌人

| 类型 | 生命 | 速度 | 伤害 | 攻击范围 | 攻击间隔 | 前摇 | 经验 | 击退抗性 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 普通僵尸 | 60 | 62 | 8 | 58 | 1.2s | 0.35s | 8 | 1.0 |
| 路障僵尸 | 100 | 58 | 10 | 62 | 1.3s | 0.4s | 12 | 0.9 |
| 铁桶僵尸 | 180 | 48 | 14 | 66 | 1.5s | 0.5s | 18 | 0.55 |
| 快速僵尸 | 45 | 105 | 6 | 54 | 0.9s | 0.25s | 6 | 1.2 |
| 精英铁桶 | 340 | 52 | 18 | 70 | 1.4s | 0.5s | 35 | 0.35 |
| 僵尸王 | 1200 | 55 | 见 5.6 | — | — | — | 100 | 0.15 |

AI 规则：

- 从右侧生成，向玩家移动，进入攻击范围后停下。
- 攻击前摇期间头顶显示感叹号/红光提示；前摇结束若玩家仍在范围内则造成伤害，否则落空。
- 受击硬直 0.2s，硬直期间不移动不攻击；击退距离按抗性折算。
- 生命归零后播放 0.4s 倒地动画再移除。
- 精英铁桶用 `filter: hue-rotate()` 与 1.3 倍缩放区分。

### 5.5 闯关模式流程

每屏战斗：

1. 玩家进入屏幕，镜头锁定，右侧出现无形屏障。
2. 敌人分 2 批从右侧出现，批间隔 1.2s，单批内每 0.6s 生成一只。
3. 当前屏敌人全灭后，显示「本段清空，继续前进」，屏障解除。
4. 玩家走到屏幕右边界后镜头解锁，进入下一屏。

敌人配置：

| 屏幕 | 第一批 | 第二批 | 追加 |
| --- | --- | --- | --- |
| 第 1 屏 | 3 普通 | 1 普通 + 2 路障 | 无 |
| 第 2 屏 | 2 路障 + 2 快速 | 1 普通 + 1 铁桶 | 1 精英 + 2 普通 |
| 第 3 屏 | 2 路障 + 2 铁桶 | 2 快速 + 2 普通 | 1 精英 + 2 路障 |
| Boss 屏 | 僵尸王 | — | — |

- 第 3 屏清空后提示「前方就是僵尸王」。
- 进入 Boss 屏后镜头锁定在 3840，Boss 从右侧登场，播放咆哮与屏幕震动。

胜利结算：

- 击败 Boss 后播放胜利音效，弹出结算：用时、击杀数、最高连击、达到等级。
- 按钮：再玩一次（重置闯关）、返回主菜单。

失败结算：

- 生命归零后弹出结算：到达屏数、击杀数、最高连击、达到等级。
- 按钮：重新挑战、返回主菜单。

### 5.6 Boss：僵尸王

外观：`assets/zombie.png` 放大 1.8 倍，叠加 CSS 王冠、铁桶护甲与暗红光晕；50% 血进入二阶段，眼睛发红光、移动与出招加快。

基础行为：

- 缓慢逼近玩家，攻击间隔 2.2s，随机选择招式，同一招式不会连续使用超过 2 次。
- 被击退距离很小（抗性 0.15）。

招式：

1. **冲撞**：前摇 0.7s（低头 + 红光），随后以 700 px/s 向前冲 0.5s；命中造成 26 伤害与强击退，撞到屏幕边界后眩晕 0.8s。
2. **跳砸震地**：前摇 0.8s，跳向玩家当前位置，落地产生向左右扩散的地面震波（速度 260 px/s，伤害 20）；震波贴地，跳跃可躲。落地后硬直 1s。
3. **召唤**：血量首次低于 60% 和 30% 时各触发一次，召唤 2 普通 + 1 路障，召唤动作 0.8s。

二阶段（生命 ≤ 50%）：

- 移动速度提升 20%，攻击间隔缩短 20%，冲撞与跳砸前摇各减少 0.1s。
- 屏幕边缘出现暗红呼吸光效。

Boss 屏边界：

- 玩家被限制在 3840–5120 内，不能后退离开。
- Boss 血量显示在屏幕顶部中央的大血条。

### 5.7 无尽模式

- 固定单屏，玩家在 60–1220 内活动，敌人从右侧生成。
- 波次间隔 3 秒，波次开始时横幅提示「第 N 波」。
- 每波敌人数量：`min(12, 3 + floor(N * 1.2))`。
- 属性成长：
  - 生命倍率：`1 + 0.08 * (N - 1)`
  - 伤害倍率：`1 + 0.05 * (N - 1)`
  - 速度倍率：`min(1.4, 1 + 0.02 * (N - 1))`
- 每 5 波追加 1 只精英（不占普通怪数量）。
- 每 10 波出现僵尸王；Boss 生命按 `1200 * (1 + 0.3 * 已出现次数)` 递增，普通怪照常生成。
- 每波结束回复最大生命的 15%。
- 玩家阵亡后结算：到达波次、击杀数、最高连击、达到等级。
- 若本局波次高于历史记录，写入 `localStorage` 并提示「新纪录」。
- 结算按钮：再来一局、返回主菜单；主菜单无尽入口显示最佳波次。

### 5.8 局内肉鸽升级

经验获取：

- 初始等级 1、经验 0。
- 击杀立即获得该敌人的经验，飘出 `+XP` 数字，不产生需要拾取的经验球。
- 升级所需经验：`30 + 20 * (当前等级 - 1)`。
- 升级时游戏暂停，弹出 3 张强化卡；若一次升多级，逐次弹出。
- 卡片可用鼠标点击或数字键 `1/2/3` 选择。

强化池（除二段跳外均可叠加）：

| 强化 | 效果 |
| --- | --- |
| 奶香重拳 | 普攻伤害 ×1.2 |
| 疾风连击 | 普攻攻速 ×1.12 |
| 铁头功 | 重击伤害 ×1.3，击退 ×1.25 |
| 龙息精炼 | 喷火伤害 ×1.3 |
| 深呼吸 | 喷火冷却 ×0.8 |
| 灵活走位 | 移动速度 ×1.1 |
| 奶量充足 | 最大生命 +20，并立即回满 |
| 越战越勇 | 每次击杀回复 2 生命 |
| 二段跳 | 解锁二段跳；仅可获得一次，拥有后移出卡池 |
| 空中霸主 | 跳劈伤害 ×1.4，判定范围 ×1.2 |
| 冲刺大师 | 冲刺冷却 ×0.75，无敌时间 +0.1s |
| 连击大师 | 第三段连击范围 ×1.3，伤害 ×1.15 |

- 每次随机抽取 3 个不同强化；卡池抽空时提供「元气恢复」：回复 30% 最大生命。
- 已获得强化在 HUD 左上角以小型图标排列，悬停显示名称与层数。

### 5.9 HUD 与界面

- 右上：技能冷却图标（J/K/L/Shift）、音效开关、暂停按钮、返回主菜单。

## 8. 验收标准

- 打开 `index.html` 显示标题画面，无控制台报错。
- 冒险模式进入 `game.html`；奶龙战僵尸弹出模式弹层，两个入口分别带正确 `mode` 参数进入 `action.html`。

## 10. 风险与对策

- **范围较大**：按上述阶段实施，每阶段结束可运行、可试玩。
- **数值手感**：全部数值集中在 `action-data.js`，试玩后统一调整。
- **DOM 性能与泄漏**：实体复用 + 重开清理 + 特效上限。
- **file:// 下 localStorage 异常**：所有读写包 `try/catch`。
- **Boss 复用素材显平**：放大、王冠、护甲、光晕、屏幕震动与二阶段视效补足。
- **按键与浏览器冲突**：游戏进行中对方向键、空格、Shift 等调用 `preventDefault()`，输入框场景不存在。
